# Momentum Crypto Scanner (نظام الزخم ورادار الانفجارات)

تطبيق متقدم لمسح وتحليل سوق العملات الرقمية بتقنيات الذكاء الاصطناعي، معاد بناؤه بالكامل باستخدام **React 18** و **TypeScript** و **Vite** و **Tailwind CSS**.

## المميزات الرئيسية (Core Features)

### النظام 1: الماسح الآلي اللحظي (Momentum System 1)
- **مؤشر الذكاء الاصطناعي للسوق (Market Matrix)**:
  - حساب نسبة صحة وأمان السوق (Market Score).
  - تصنيف السوق بألوان ديناميكية (أخضر خاااااارق، ذهبي إيجابي بحذر، أحمر سلبي وخطر).
  - سجل تغيرات السوق التاريخية لآخر 5 فترات زمنية.
  - خيار الحماية الآلية (Auto-Kill) لمنع الدخول وقت هبوط السوق مع مزامنة فورية على Firebase Firestore.
- **إعدادات الرادار والاستراتيجيات**:
  - تفعيل وتعطيل استراتيجيات متعددة: الزخم (Momentum)، الاختراق (Breakout)، القناص (Sniper)، وسكالبينج (BB & RSI).
  - ضبط الإطار الزمني (1m, 5m, 15m, 1h, 4h).
  - ضبط وقف الخسارة الأولي (%)، هدف الملاحقة (%)، مسافة الملاحقة (%)، مضاعف الفوليوم، وفترة التبريد.
  - حفظ وتطبيق الإعدادات على قاعدة البيانات السحابية مع مؤشرات تفاعلية.
- **إحصائيات الأداء المتكاملة**:
  - فلاتر زمنية متعددة (1h, 4h, 6h, 12h, 24h, 7d, 30d, كل الأوقات).
  - إجمالي الصفقات، معدل النجاح (Win Rate)، صافي الربح (% PnL)، وعدد الصفقات المفتوحة مع الأرباح العائمة (Floating PnL).
- **إدارة الصفقات المفتوحة**:
  - أسعار لحظية متدفقة عبر **Binance WebSocket** (`!miniTicker@arr`).
  - تحديث فوري لنسب الأرباح/الخسائر المباشرة وتصنيف البطاقات حسب الربح، القوة (Score)، أو التاريخ.
  - إشارات قوة الصفقة الحية (Live Score) وتفصيل درجات مؤشرات الدخول (Trend, Volume, RSI, Setup, BTC Health, Candle).
  - تنبيهات الانعكاس والتشبع ومؤشرات الملاحقة السعرية النشطة.
  - إمكانية الإلغاء والحذف الفوري والربط المباشر بصفحة التداول على باينانس.
- **إضافة الصفقات اليدوية**:
  - فحص الرموز وجلب السعر الحالي آلياً من Binance API وإضافتها للمتابعة الحية.
- **سجل الصفقات المغلقة**:
  - عرض آخر الصفقات المغلقة مع مدة الصفقة الدقيقة (ساعات ودقائق)، ونسبة الربح النهائي، وحذف السجل عند الحاجة.
- **نظام التنبيهات الصوتية**:
  - مؤثرات صوتية مبنية على Web Audio API لتنبيهات فتح الصفقات والصفقات الرابحة مع إمكانية التفعيل والإيقاف.

### النظام 2: رادار الانفجارات الشامل (Explosion Radar System 2)
- محرك مسح وتدقيق مباشر يعمل من جهة العميل (Client-Side) عبر واجهات Binance الرسمية.
- فلترة جميع أزواج USDT النشطة في السوق ذات السيولة الحقيقية (أكثر من 3 ملايين دولار) مع استثناء العملات المستقرة.
- اختيار أطر زمنية متعددة للتحليل (5m, 15m, 1h, 4h, 1d).
- حساب مؤشرات البولينجر باندز (Bollinger Bands Bandwidth) لاكتشاف الانضغاط السعري الحاد (Squeeze).
- رصد بصمة الحيتان (Whale Volume Spike) مقارنة بمتوسط 20 فترة.
- فحص الاتجاه باستخدام المتوسط الأسي (EMA 50) والمسافة إلى الحد العلوي للقناة.
- بطاقات مخصصة لكل عملة مرشحة توضح السعر، نسبة الانضغاط، الهدف الصعودي المتوقع (+%)، وقوة الإشارة، مع رابط فحص مباشر على باينانس.

## التقنيات المستخدمة (Tech Stack)
- **Framework**: React 18 (TypeScript)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, Cairo Arabic Typography
- **Database & Realtime**: Firebase Firestore
- **Live Streams & Data**: Binance WebSocket API & Binance REST API
- **Icons & Sounds**: Lucide React & Web Audio API
- **Backend Service**: Node.js, Firebase Admin SDK

## هيكلة المشروع الموحد (Unified Monorepo Structure)
```
├── backend/                     # محرك الباك إند والماسح السحابي
│   ├── server.js                # خادم محرك المسح، تقييم السوق، والملاحقة الآلية
│   ├── serviceAccountKey.json   # مفتاح اعتماد Firebase Admin السحابي
│   └── package.json             # حزم واعتماديات الباك إند
├── src/                         # واجهة المستخدم والتطبيق الأمامي (React + Vite)
│   ├── components/              # مكونات النظام 1 والنظام 2
│   ├── firebase.ts              # إعدادات العميل لقاعدة البيانات
│   ├── types.ts                 # نماذج البيانات والأنواع
│   └── App.tsx                  # الحاوية الرئيسية للتطبيق
├── package.json                 # الاعتماديات العامة وأوامر التشغيل
└── README.md
```

### أوامر التشغيل:
- تشغيل واجهة المستخدم (Frontend): `npm run dev`
- تشغيل محرك الباك إند (Backend Engine): `npm run start:backend` (أو `cd backend && npm start`)
- بناء المشروع: `npm run build`
